# paumirallweb

La web de Pau Miralles, fotógrafo y videógrafo. Publica el portfolio, entrega el
material a los clientes y lleva la administración del negocio, con una sola base
de datos y un solo sistema de diseño.

Tres zonas: pública en `/`, cliente en `/c/:token` con token y PIN, y
administración en `/admin` con Google Sign-In.

## Estado

Pre-construcción. Aquí solo hay documentación. La fase 0 del
[plan de ejecución](docs/plan-de-ejecucion.md) crea el proyecto.
